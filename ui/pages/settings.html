About dependencies

What YouLoad checks and how updates are handled.

YouLoad

The main application. Its releases are checked through the official YouLoad GitHub repository.

PySide6

Provides the Qt-based desktop application framework used by YouLoad.

PySide6 Essentials

Provides core Qt Python bindings and modules used by the application.

PySide6 Addons

Provides additional Qt modules used by the desktop interface and supporting features.

Shiboken6

Provides the binding support used by PySide6.

yt-dlp

Handles video and media information retrieval and the download layer used by YouLoad.

FFmpeg

Handles media processing tasks such as stream merging and format conversion when required.

Why some updates say "Included in app update"

Components such as PySide6 are part of the packaged YouLoad runtime. Replacing them while YouLoad is running is unsafe, so their updates are delivered with a newer YouLoad release instead.
