About YouLoad

A desktop video downloader developed by NISPAX InfoTech.

What is YouLoad?

YouLoad is a desktop application built to fetch video metadata and provide a local interface for downloading supported online video content.

How it is built

The application uses Python for its desktop and application layer, Qt through PySide6 for the desktop interface, and HTML, CSS and JavaScript for the user interface.

Video metadata and download operations are handled through yt-dlp. FFmpeg is used when media processing or stream merging requires it.

Technology

Python · PySide6 · Qt WebEngine · HTML · CSS · JavaScript · yt-dlp · FFmpeg

Application structure

The UI is separated into individual page documents for Home, Download, Queue, History, Settings, About and Disclaimer. The Python layer handles application services and communication with the web interface.

Third-party software

YouLoad uses third-party software and libraries. Their own licenses, copyright notices and distribution requirements continue to apply. Official releases should include the applicable third-party notices alongside the bundled components.

Development

YouLoad is designed as a modular Windows desktop application so the interface, download engine, bundled components and updater can evolve independently.
